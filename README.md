# Claudi CLI Workspace

Welcome to the **Claudi CLI** workspace. This monorepo is a strategic integration project that bridges the gap between **Gemini's seamless ecosystem** and **high-performance Rust-based agent harnesses**.

**The core mission of this codebase is to provide a robust, cross-platform path for using Gemini CLI's "Sign in with Google" authentication directly within the `claw-code` Rust client.**

## 📂 Repository Components

This workspace consists of two primary projects working in tandem:

### 1. [Claw Code](./claw-code)
**Claw Code** is a high-performance Rust implementation of a CLI agent harness. It is designed for developers who need a fast, build-from-source agent that can leverage various model providers.

*   **Language:** Rust
*   **Key Features:** Parity-driven development, deterministic mock-service harness, and lightweight execution.
*   **Now with Windows Auth:** Recently updated to support secure, cross-platform token generation, allowing it to load Gemini CLI credentials on both Linux and Windows.

### 2. [Gemini CLI](./gemini-cli)
**Gemini CLI** is the official terminal-first AI agent powered by Google's Gemini models. It provides the foundational authentication layer and rich tool capabilities.

*   **Language:** TypeScript (Node.js/React/Ink)
*   **Key Features:** Seamless "Sign in with Google" OAuth, 1M+ token context window, Google Search grounding, and MCP support.

## 🚀 Recent Breakthrough: Cross-Platform Gemini Auth

We have successfully bridged the authentication gap. The `claw-code` Rust runtime can now:
- **Share Credentials:** Automatically detect and use the `oauth_creds.json` generated by the Gemini CLI.
- **Run on Windows:** Securely generate OAuth state and PKCE tokens on Windows using system-native entropy (via `getrandom`), removing the previous dependency on Linux-only `/dev/urandom`.
- **Dynamic User Resolution:** Zero hardcoded paths; the system dynamically resolves home directories across Linux and Windows to find your `.gemini` config.

## 🛠️ Getting Started

### 1. Set up Gemini Auth
First, use the Gemini CLI to sign in:
```bash
cd gemini-cli
npm install && npm run build
npm run start # Choose "Sign in with Google"
```

### 2. Run Claw Code with Gemini Auth
Then, run the Rust client which will automatically pick up your Gemini session:
```bash
cd claw-code/rust
cargo build --workspace
./target/debug/claw prompt "Check my auth status"
```
